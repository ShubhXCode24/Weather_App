# 🌦️ Weather App

A modern and responsive Weather Application built using **HTML, CSS, and JavaScript** with real-time weather data powered by the **OpenWeather API**.

---

## 🚀 Live Features

✅ Search weather by city name
✅ Real-time temperature updates
✅ Dynamic weather icons
✅ Wind speed & humidity details
✅ Error screen for invalid cities
✅ Responsive design for mobile & desktop
✅ Smooth UI animations and transitions
✅ Enter key support for quick search

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API
* Font Awesome
* Google Fonts

## ⚙️ How To Run

1. Download or clone the repository

```bash
git clone https://github.com/ShubhXCode24/weather-app.git
```

2. Open the project folder

3. Run `index.html` in your browser
